
# Aurora's N Coffee

## Descripción del proyecto

*Aurora's N Coffee* es un proyecto web relacionado con una cafetería. Su objetivo es ofrecer una experiencia visual agradable 
y facilitar la consulta de información sobre el establecimiento.

## Características

- Diseño web atractivo.
- Interfaz sencilla y fácil de utilizar.
- Información sobre la cafetería.

## Instalación y uso

1. Descarga o clona este repositorio.
2. Abre la carpeta del proyecto.
3. Localiza el archivo `Prueba.html`.
4. Abre el archivo en tu navegador para visualizar la página.
