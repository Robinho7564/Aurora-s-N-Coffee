# Aurora-s-N-Coffee

## Introducción
Pagina web de un negocio de cafeteria 

### Objetivos
Facilitar el trabajo :v

## Descripción del Proyecto
Este es un proyecto *muy util* desarrollado para **demostrar habilidades** en Markdown.

Aquí combinamos **texto en negrita** con *texto en cursiva* para dar énfasis y sea clave lo que se quiera decir.

## Procedimiento de Instalación
1. Clonar el repositorio desde GitHub a tu máquina local.
2. Abrir la carpeta del proyecto en el editor de código.
3. Ejecutar el comando npm install para instalar las dependencias.
4. Iniciar la aplicación con el comando npm start.
